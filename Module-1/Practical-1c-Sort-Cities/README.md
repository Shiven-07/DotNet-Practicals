# Module 1 - Practical 1c: Arrange Names of Cities in Sorted Order

To write a C# program that accepts names of 10 cities from the user and displays them in sorted (alphabetical) order.

## Setup and source limitations

Create a C# Console App named SortCities in Visual Studio, replace its Program.cs, then run with Ctrl+F5. Each practical is an independent program; do not combine the entry points in a single project.
